# YouTube SEO notes

## Principle

Optimize for human clarity first.

For Shorts, metadata can help YouTube understand the subject, but viewer response and topical consistency matter much more than keyword density.

## Highest-priority work

### Titles

Use titles that match real questions or clearly identify the subject while still sounding human.

Good:
- Jesus was only amazed twice.
- Why Is Faith Required for Salvation?
- What if God loves you?

Avoid turning titles into generic SEO copy such as:
- Bible Verse Explained | Christian Faith
- Christian Question About Jesus

Retitle older Shorts only when the existing title is genuinely unclear and the replacement is clearly better. Do not mass-retitle the archive.

### Topic consistency

Keep the channel recognizably centered on:
- Jesus
- the Bible
- doubt
- grace
- hard passages
- difficult Christian questions

Topic drift is a bigger concern than imperfect metadata.

### Descriptions

Use one plain opening sentence that identifies the actual topic.

Then add context or a scripture reference only when useful.

Do not repeat the same keyword-heavy boilerplate under every video.

There is no need to force Christianity / Jesus / Bible / faith into every description if the subject is already obvious.

## Useful channel-level work

### Channel description

Preserve the channel voice first. The description is primarily a human clarity / conversion surface, not a major Shorts-ranking lever.

Current recommendation:

Jesus is the point.
The rest is just paying attention.
That's Christianity, apparently.

Short, honest videos about Jesus, the Bible, doubt, and grace, including the hard passages and the questions Christians tend to answer too fast.

christianityapparently.com

### Playlists

Use 3–5 real topical groupings once enough videos fit naturally.

Possible groups:
- Questions About Jesus
- Hard Passages
- Faith & Doubt
- Grace
- Questions About God

Do not create one-video playlists or playlists solely to manufacture keywords.

### Homepage

Use the homepage for human orientation and conversion:
- featured video / trailer if useful
- Shorts shelf
- a few strong topical playlists

Do not overbuild the homepage.

## Low priority / optional

### Channel keywords

Optional. Use a few honest terms if desired, but do not expect a meaningful discovery effect.

### Hashtags

Optional. Use only when they genuinely add context. Do not add #Shorts just because the video is a Short.

## Skip

### Tags

Skip routine tag work. They are low value and mainly useful for misspellings or unusual alternate names.

### Keyword stuffing

Do not stuff Christian / Christianity / Jesus / Bible into every title or description.

### Mass-retitling

Do not mass-retitle older Shorts. It muddies our own test data and is unlikely to justify the effort.

## Analytics check before more SEO work

Check YouTube Studio → Analytics → Reach / Traffic source → YouTube Search.

If search is a small share of Shorts traffic, treat further SEO work as secondary to:
- hook strength
- swipe-away rate
- completion
- rewatches
- satisfaction
- topic consistency

Do not use a fixed percentage threshold as a rule. Use the channel's actual traffic mix to decide how much more time SEO deserves.

## Change logging

Because YouTube Studio does not annotate every metadata edit in a useful way, keep dated GitHub checkpoints whenever titles/descriptions are changed.

The goal is to preserve our own experiment history, not to avoid an algorithm penalty.
