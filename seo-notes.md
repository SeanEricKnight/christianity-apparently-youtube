# YouTube SEO notes

## Principle

Optimize for clarity, not keyword density.

YouTube needs enough plain-language context to understand what a video is about. The viewer still needs a title that feels human.

## Channel-level priorities

1. Put the core subjects in the channel description: Christianity, Jesus, Bible, faith, doubt, grace.
2. Link the website.
3. Use clear topical playlists once enough videos exist.
4. Keep the channel homepage organized around viewer questions rather than upload chronology alone.
5. Preserve the channel's voice. Avoid generic Christian-marketing language.

## Video-level priorities

### Titles

Prefer titles that either:
- contain the actual subject, or
- create a strong open loop while the description supplies the subject.

Good examples already on the channel:
- Jesus was only amazed twice.
- Why Is Faith Required for Salvation?
- What if God loves you?

More opaque examples need stronger descriptions:
- Forsaken.
- The Original “Follow Me”
- You are not alone.

### Descriptions

For each Short, use 1–3 natural sentences.

A good description should usually contain:
- the actual question/topic
- Jesus / Christianity / Bible / faith where relevant
- the scripture reference when the Short is based on a specific passage

Do not repeat the same boilerplate paragraph under every video.

### Tags

Low priority. Use mainly for:
- spelling variants
- alternate names
- scripture references
- terms people genuinely use for the subject

### Playlists

Recommended working groups once there are enough videos:
- Questions About Jesus
- Faith & Doubt
- Bible Questions
- Questions About God
- Salvation & Grace

Do not create thin playlists containing one video just to manufacture keywords.

## Immediate title notes

No mass renaming.

The current Shorts are a test bed, so title changes should be treated as experiments rather than a rewrite of the catalog.

The two clearest candidates for a future title test are:
- The Original “Follow Me” → a version that explicitly names Jesus
- Forsaken. → a version that explicitly names Jesus or the cross

Keep the historical title in `BASELINE-2026-10-02.md` before any live change.
